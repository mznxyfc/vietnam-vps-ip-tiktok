## 住宅IP、原生IP、双ISP：先分清这几个词再掏钱

这四个词描述的是同一个问题的不同侧面：这个 IP 在平台风控系统里，像不像越南本地真实用户。

机房 IP 来自数据中心地址段，配置再高，属性一查就露馅，被平台标记为机房来源的概率远高于其他类型。原生 IP 指注册地和实际地理位置都在越南，没经过代理广播，能定位到当地、解锁本土服务。住宅 IP（也叫家宽 IP）来自宽带运营商分配给家庭用户的地址段，是风控系统里信任度最高的一类。双ISP 则是同一个 IP 同时带两个运营商属性，在常见的 IP 风控评分工具里欺诈分通常很低——这是商家的说法，下单前可以拿公开的检测工具自己验证一遍。

三个属性叠在一起，才构成“越南住宅 VPS”比普通越南机房 VPS 贵的理由。差价买的就是这个身份，所以掏钱前先确认业务到底需不需要它。
